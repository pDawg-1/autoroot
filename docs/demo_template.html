A reproducible analyst workflow

01 / Model and validate. Seeded demand, seasonal cycles, trend, and noise form a complete segment panel. DuckDB holds one fact table and three dimensions.

02 / Monitor with prior data. Rolling Z-score compares with the previous 12 weeks. Robust seasonal regression estimates trend and annual components. Isolation Forest trains on historical level, WoW, and YoY features.

03 / Catch local changes. Segment seasonal alerts help find disruptions diluted in company totals. More comparisons increase false-alert risk.

04 / Reconcile the drivers. Actual minus the preceding four-week average gives each cell's delta. Signed contributions sum to the total. A revenue bridge separates unit and price changes.

05 / Verify the explanation. Sales indicate where movement occurred. Validate inventory, campaign, pricing, and operational evidence before establishing why.

Scope and limits

Two annual cycles, a clean initial calibration period, fixed thresholds, and one-week synthetic events make this a controlled demonstration. Early YoY values are unavailable. Production monitoring needs longer history, holdout evaluation, alert budgets, and controls for multiple testing.

This public demo is a standalone report exported by Python. The sample dashboard explores prepared results. The Analyze my CSV page runs fresh analysis in your browser. The full Streamlit application and reproducible pipeline are in the repository.
